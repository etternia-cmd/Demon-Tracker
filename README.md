# Geometry Dash Demon Tracker

A personal little website for keeping track of the Geometry Dash demons I've beaten.

## Features

- Add new demons
- Edit demon information
- Delete demons
- Drag and drop Insane/Extreme demons to create a custom difficulty ranking
- Separate Hard Demon section
- Track attempts
- Add personal notes
- Search and filter demons
- Sort demons
- Export the tracker to CSV
- Automatically saves changes in the browser using localStorage

## Disclaimer

This is **NOT a university assignment or university project**.

This is purely a personal project that I made for fun to keep track of my Geometry Dash demon completions, attempts, opinions, and personal difficulty rankings.

The project is not affiliated with, submitted to, or created for any university course.

## Technologies

- HTML
- CSS
- JavaScript
- Browser localStorage

## About

The tracker is designed around my personal Geometry Dash progression and opinions. Demon difficulty rankings are subjective and can be changed at any time using the drag-and-drop system.

More features and visual improvements may be added in the future.
